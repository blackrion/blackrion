## 公开项目

### [Umans Status Panel](https://github.com/blackrion/umans-status-panel)

在 Snow CLI 终端中查看 Umans.ai 的实时服务状态。

查看网关与模型的可用性、吞吐量、首 Token 延迟和近期事件；每 30 秒自动刷新，也支持手动刷新。

`JavaScript` · `Node.js 18+` · `Snow CLI AnyPanel` · `零外部依赖`
