# Orion

网络运维自动化、AI Agent 工具与个人知识管理。

## 公开项目

- [hermes-companion](https://github.com/blackrion/hermes-companion)：Hermes Agent 的陪伴型插件，提供情绪状态、心跳、梦境整合和主动关怀能力。
- [umans-status-panel](https://github.com/blackrion/umans-status-panel)：Umans.ai 的实时服务状态面板。
- [local-evolver](https://github.com/blackrion/local-evolver)：纯本地、无外部依赖的 AI Agent 自进化引擎。
